Connect Vercel

Apna Vercel Access Token paste karo. Token banane ke liye:

  1. Vercel dashboard → Settings → Tokens
  2. Create Token dabao, koi bhi naam do
  3. Scope Full Account select karo, token copy karo
vercel.com/account/tokens kholo →

Connect Netlify

Apna Netlify Personal Access Token paste karo. Token banane ke liye:

  1. Netlify dashboard → User settings → Applications
  2. Personal access tokens section me New access token
  3. Naam do, expiration set karo, token copy karo
app.netlify.com/user/applications kholo →

Connect Render

Apni Render API Key paste karo. Key banane ke liye:

  1. Render dashboard → Account Settings
  2. API Keys section me Create API Key
  3. Naam do, key copy karo
dashboard.render.com/u/settings kholo →
